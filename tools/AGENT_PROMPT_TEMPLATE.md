# Template Mínimo para Pesquisa de Executivos RN

## Versão Curta (Usar para agentes)

```
PESQUISA RÁPIDA — sem sub-agentes, sem linkedin.com direto.

5 empresas RN, 1 executivo principal cada:

1. [EMPRESA A] (R$ XXX mi capital)
2. [EMPRESA B] (R$ XXX mi capital)
3. [EMPRESA C] (R$ XXX mi capital)
4. [EMPRESA D] (R$ XXX mi capital)
5. [EMPRESA E] (R$ XXX mi capital)

FORMATO: Empresa | Nome | Cargo | Confiança | Fonte | LinkedIn
```

## Regra Única (Obrigatória)

- **NÃO invente nomes.** Se não achar, diga "não encontrado".

## Pronto pra usar

Copie acima, substitua empresas, cole no agente.
Reduz distração, acelera +20% resposta agente.

| Antes                                   | Depois                         |
